# Roadmap

## D001 — Foundation and read-only delegation

Status: active

- Establish canonical project documentation.
- Package LazyCode as an out-of-tree Harness bundle.
- Prove Project Manager to Explorer delegation with structured evidence.
- Verify the child cannot access mutation, shell, or network tools.

## D002 — Durable organizational state

- Define versioned project, delivery, feature, agent, task, and report schemas.
- Reconstruct persistent responsibility from artifacts and repository state.
- Add lifecycle transitions and auditable state validation.

## D003 — Context builder

- Select role- and task-specific documents and source files.
- Track context provenance and token budgets.
- Add upward report compression without silently losing blockers.

## D004 — Authority and escalation

- Model resource-scoped capabilities and temporary leases.
- Add deterministic permission and escalation routing.
- Introduce read-only Oracles and human escalation connectors.

## D005 — Delivery workflow

- Implement Delivery Manager and Feature Lead contracts.
- Coordinate recursive implementation, integration, independent review, and testing.
- Evaluate multiple model adapters and external subagent providers.
